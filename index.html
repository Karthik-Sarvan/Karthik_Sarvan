Hardware-in-the-Loop (HIL) Firmware Validation

Bare-Metal STM32 · C & Rust

Firmware teams routinely wait weeks to months for physical PCB fabrications. Mimic bridges that gap by running directly on bare-metal STM32 microcontrollers, acting as a physical I2C/SPI slave peripheral to emulate complex multi-sensor payloads and synthetic fault states in real time.

Enables automated unit testing of control loops, strict PID tuning, and bus recovery firmware in CI before silicon arrives. 

/* Real-time I2C slave event interrupt handler */
void mimic_i2c_event_isr(I2C_TypeDef *i2c) {
    if (i2c->ISR & I2C_ISR_ADDR) {
        i2c->ICR |= I2C_ICR_ADDRCF;
        mimic_bus_handle_address_match(i2c);
    }
    if (i2c->ISR & I2C_ISR_TXIS) {
        i2c->TXDR = mimic_synthetic_sensor_next_byte();
    }
}
